### Project要求：

1. [project题目参考](Lab.pdf)
2. 2～3人组队。团队合作也是project考核因素，必须要组队参加。
3. 实验报告内容如下：每个题目按Project 00-00的要求写文档，并按题目序号将所有文档整合成实验报告。实验报告的开头需要写明小组每个成员的贡献（比如XXX负责了XX实验的XX模块等）。
4. 小组成员都需要为实验报告和代码做贡献。
5. 课堂会有老师抽查环节。
6. 题目难度不大，同学们在实验报告中主要说明自己针对题目进行的新颖特别的思考/尝试/代码实现，以及实现了怎样的性能和效果，包括但不限于，是不是速度更快了？精度更高了？能泛化到更多的测试样例上？以及其他等等。
7. project提交方式：

   7.1. 邮件请使用正常附件，不要使用超级附件，会影响下载。

   7.2. 以小组为单位发送附件到邮箱【dip_cse_sysu@163.com】。邮件主题、附件压缩包、和实验报告都命名为【姓名1学号1_姓名2学号2_姓名3学号3_第X次project】（X为汉字一二三四，例如【张三13333333_李四13333334_第一次project】）。

   7.3. 附件和主题必须包含关键词“第X次project”（X为汉字一二三四），否则会影响附件下载和打分，望周知。邮件正文不要空白，避免被邮箱误判为垃圾邮件。

   7.4. 压缩包附件需要包括实验报告PDF+可运行代码，Matlab或Python代码皆可。实验报告（注1：可运行代码是指你的代码在课室电脑上点击运行后，无需其他任何操作就能输出预期结果）（注2：教室电脑系统是window，使用mac的同学注意压缩包解压后是否有乱码。）（注3：代码中建议使用文件夹中的相对路径，否则在教室电脑运行时会因为路径问题报错）
